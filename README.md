# fetchflag

Fetch HTML/Markdown flag fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/fetchflag/

## Install / run

```bash
git clone https://github.com/theworker02/fetchflag.git
cd fetchflag
node src/cli.js
node --test
```
